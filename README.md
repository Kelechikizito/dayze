# Dayze

Dayze lets employers stream salaries to workers second by second on Arbitrum, with every rate, balance and withdrawal encrypted using Fhenix CoFHE, so no one onchain can see what anyone earns. Employers keep oversight in two ways: an audit key can decrypt payroll, and approval rules (like "salaries over $10k/month need a second approver") are checked against the encrypted amounts without revealing them. Workers can issue an expiring Income Credential that proves to a specific landlord or lender that they earn at least $X a month, without revealing their actual salary.
